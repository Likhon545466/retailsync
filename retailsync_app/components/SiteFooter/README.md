# SiteFooter Component

## Purpose
The `SiteFooter` provides a minimalist colophon at the base of the page. It confirms system health, synchronization timestamp, software version, academic deliverables suite links, and documentation access in a single typographic ruled section.

## Constraints Adherence
- Hairline top border (`border-top: var(--hairline-w) solid var(--border-hairline)`).
- Zero card containers, gradient backgrounds, or badges.
- Single accent color for interactive link hovers.
- Clean typographic metadata: `IBM Plex Mono` for timestamps and versions.

## Elements
- System status line: Green 6px status dot + "Telemetry synced 02:00 BST".
- Core links: Proposal (PDF/DOCX), 70-page Master Technical Engineering Suite, Defense Slide Deck, Team Pack ZIP.
- Colophon metadata: RetailSync v2.0-RELEASE • Capstone Engineering Project • Daffodil International University.
